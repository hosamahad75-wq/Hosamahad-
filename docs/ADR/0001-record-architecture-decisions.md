# 0001 — Record architecture decisions

- Date: 2026-07-31
- Status: Proposed
- Deciders: Project maintainers

Context

We want to record key architectural decisions so that future contributors can understand why we chose one approach over another. Decisions include choices of frameworks, major libraries, deployment models, and security approaches.

Decision

Adopt a lightweight ADR process using Markdown files stored under `docs/ADR/`. Each ADR will include the following sections:

- Status
- Context
- Decision
- Consequences
- Date
- Authors

Consequences

- Improved project documentation and historical context for architectural choices.
- Slight overhead on contributors to write a short ADR when making significant decisions.

Notes

This is the initial ADR to establish the process. Subsequent ADRs should follow the template and increment the file number.
