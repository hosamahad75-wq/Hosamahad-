# Security Policy

Thank you for taking the time to responsibly disclose security vulnerabilities in this project. We take security seriously and will respond to reports promptly.

## Reporting a Vulnerability

Please report security vulnerabilities by one of the following methods (in order of preference):

1. Use GitHub's Security Advisories feature for this repository: https://github.com/hosamahad75-wq/Hosamahad-/security/advisories (if enabled).
2. Open an issue in this repository and add the `security` label. Note: Issues are public, so avoid sharing sensitive details there. If you must share sensitive information, please use method (1) or email.

If you prefer email and have a secure channel for sensitive details, you may contact the maintainers at: security@hosamahad.local (replace with a real address configured for this project).

## What to include

Please include:
- A description of the vulnerability and the component(s) affected.
- Steps to reproduce the issue, including any code samples or proof-of-concept.
- The impact and potential mitigations you recommend.

## Response

We aim to acknowledge reports within 7 days and provide a patch or mitigation plan within 30 days for high-severity issues, depending on complexity and impact.

## Supported Versions

Security fixes will be provided for the latest stable release and the current development branch. If you maintain a fork or patched version, please ensure you merge security fixes from upstream.

## Disclosure Policy

We follow coordinated disclosure: we request reporters avoid public disclosure until a fix or mitigation is available and coordinated with the maintainers.

## Disclosure of Fixed Issues

Once an issue is fixed, we will publish a security advisory (if appropriate) describing the issue, the affected versions, and the remediation steps.
